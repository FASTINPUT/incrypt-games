# 인크립트 게임즈 웹사이트 — 배포 안내

정적 사이트입니다. 빌드 과정이 없으므로 Vercel에 폴더째 올리면 바로 동작합니다.

```
/
├── index.html          사이트 본문
├── og.png              카카오톡·트위터 공유 미리보기 이미지
├── favicon.svg         브라우저 탭 아이콘
├── robots.txt          검색엔진 수집 허용
├── sitemap.xml         검색엔진용 페이지 목록
├── vercel.json         캐시·보안 헤더 설정
└── images/
    ├── title.webp      타이틀 화면
    ├── play.webp       인게임 플레이 화면
    └── character.webp  메인 캐릭터
```

## 1. Vercel에 올리기

**방법 A — GitHub 연동 (권장)**

1. GitHub에 저장소를 새로 만들고 이 폴더 내용을 그대로 올립니다.
2. vercel.com에 GitHub 계정으로 로그인 → **Add New → Project**
3. 방금 만든 저장소를 선택합니다.
4. Framework Preset은 **Other**, Build Command와 Output Directory는 비워둡니다.
5. **Deploy**를 누르면 끝입니다.

이후로는 GitHub에 파일을 수정해 올릴 때마다 사이트가 자동으로 갱신됩니다.

**방법 B — 폴더 끌어다 놓기**

Vercel 대시보드에서 이 폴더를 그대로 드래그하면 즉시 배포됩니다. 다만 이후 수정할 때마다 다시 올려야 합니다.

## 2. 배포 후 반드시 할 일

### 2-1. 실제 주소로 URL 바꾸기

배포되면 `프로젝트이름.vercel.app` 주소를 받습니다. 세 파일에서 임시 주소를 실제 주소로 바꿔주세요. 공유 미리보기 이미지가 이 주소를 기준으로 불러와지기 때문에, 안 바꾸면 카카오톡에 이미지가 안 뜹니다.

- `index.html` — `incrypt-games.vercel.app`이 들어간 곳 (canonical, og:url, og:image)
- `robots.txt` — Sitemap 줄
- `sitemap.xml` — loc 줄

### 2-2. 사전예약 폼 연결하기

지금 상태로는 신청 버튼을 누르면 **메일 앱이 열립니다.** 이메일이 자동으로 수집되지는 않습니다. 자동 수집을 원하시면:

1. https://formspree.io 가입 (무료 월 50건, 카드 등록 불필요)
2. New Form을 만들고 받는 주소를 byungcookst@gmail.com으로 설정
3. 발급받은 엔드포인트 주소를 복사
4. `index.html` 아래쪽 `const FORM_ENDPOINT = '';` 의 따옴표 안에 붙여넣기

신청이 들어오면 메일로 알림이 오고, Formspree 대시보드에서 목록을 CSV로 내려받을 수 있습니다.

무료 한도가 부족해지면 Google Forms를 임베드하거나, Vercel의 서버리스 함수 + Vercel KV로 직접 만드는 방법이 있습니다. 사전예약자가 수백 명 단위로 늘어나면 그때 옮기시면 됩니다.

## 3. 도메인 연결 (나중에)

도메인은 가비아, 후이즈 같은 국내 등록기관이나 Cloudflare, Namecheap 같은 해외 등록기관 어디서 사도 무방합니다. `.com`은 보통 연 2만원 안팎입니다.

연결 순서:

1. Vercel 프로젝트 → **Settings → Domains**에 구입한 도메인을 입력합니다.
2. Vercel이 알려주는 DNS 레코드를 도메인 구입처의 DNS 설정에 그대로 입력합니다.
   - 최상위 도메인(`incryptgames.com`)은 보통 A 레코드
   - `www`는 CNAME 레코드
3. 반영에는 보통 몇 분에서 최대 하루가 걸립니다. HTTPS 인증서는 Vercel이 자동으로 발급합니다.
4. 연결이 끝나면 위 2-1의 주소들을 새 도메인으로 다시 바꿔주세요.

## 4. 확장할 때 고려할 것

지금은 페이지 하나짜리 사이트라 이 구조로 충분합니다. 아래 상황이 오면 구조를 바꾸는 걸 권합니다.

| 필요해지는 시점 | 권장 방법 |
|---|---|
| 게임이 두 개 이상 | 게임별 상세 페이지 분리 (`/games/cat-run/`) |
| 공지·업데이트를 자주 올림 | Next.js로 전환하거나 마크다운 기반 블로그 추가 |
| 회원 로그인, 랭킹 웹 연동 | Supabase 또는 Firebase 연결 |
| 영어권 출시 | `/en/` 경로 추가하고 hreflang 태그 설정 |

Next.js로 옮길 때도 이 HTML의 마크업과 CSS를 그대로 컴포넌트로 가져갈 수 있게 작성해 두었습니다.
